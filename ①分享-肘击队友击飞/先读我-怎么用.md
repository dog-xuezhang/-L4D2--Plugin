# 先读我 —— 这个文件夹是什么

这是一个 SourceMod 插件：**L4D2 肘击队友击飞**（推开队友把他打飞，带引擎"被炸飞"动画）。
当前版本 **v1.0.11**，已在你自己的服务器上跑着（线上就是这份）。

---

## 一、文件夹里每个文件是干什么的

| 文件 | 给谁用 | 说明 |
|---|---|---|
| **肘击队友击飞-完整分享包-v1.0.11.zip** | **发给别人就发这一个** | 整包（源码 + 编译好的插件 + 配置参考 + 中英说明），别人解压即用 |
| `l4d2_shove_launch.smx` | 服务器 | **编译好的插件本体**，丢进 `addons/sourcemod/plugins/` 就能用（不用编译） |

| `README.md` | 所有人 | 中英双语完整说明（依赖 / 安装 / 15 个参数 / 3 个命令 / 实现原理 / 注意事项 / 更新日志 / 许可） |

## 二、别人怎么装（三步）

1. 确认服务器装了 **Left 4 DHooks Direct**（必需，缺了插件加载会报 native 缺失）
2. 把 `l4d2_shove_launch.smx` 放进 `left4dead2/addons/sourcemod/plugins/`
3. 换图或重启后生效；`cfg/sourcemod/l4d2_shove_launch.cfg` 会自动生成，改完 `sm plugins reload l4d2_shove_launch`

## 三、常用参数速查（默认值就是你现在服务器上的值）

| 参数 | 默认 | 作用 |
|---|---|---|
| `sm_shovelaunch_enable` | 1 | 总开关 |
| `sm_shovelaunch_teammates` | 1 | 肘击队友 → 击飞 |
| `sm_shovelaunch_si` / `_tank` | 0 / 0 | 特感 / 坦克 是否也击飞 |
| `sm_shovelaunch_force` / `_up` | 600 / 350 | 水平速度 / 上抛速度（想飞更远就加 force） |
| `sm_shovelaunch_flyanim` | 2 | 动画：2=引擎原生 Fling（最像被炸飞） 1=只发 76 号动画事件 0=不改 |
| `sm_shovelaunch_physics` | 1 | 物理优先（每 tick 只设速度，动作最连贯）；0=旧版搬坐标 |
| `sm_shovelaunch_immune` | 1 | 飞行期间免伤（防队友被肘下高台摔死） |
| `sm_shovelaunch_debug` | 0 | 调试日志 |

命令：`sm_shovelaunch_status`（看设置）、`sm_shovelaunch_test <目标>`、`sm_shovelaunch_state <目标>`（后两个要 ROOT）

## 六、别人最容易踩的三个坑（分享时可以直接把这段发给对方）

1. **必须装 Left 4 DHooks Direct**（用到它的 `L4D2_CTerrorPlayer_Fling` 等 native）
2. **bot 被击飞走的是"抛物线搬运"兜底**：机器人 AI 会清掉它的速度，所以插件会自动判断（日志写 `物理推不动`）；真人则是纯物理飞行
3. **SourceMod 生成插件 cfg 时会沿用"同名 cvar 上一个版本的默认值"**：如果改了某个 cvar 的默认值，cfg 里可能还是旧值 → 换个 cvar 名或手改 cfg
